## Zenith Hardware

Implements the Zenith specification in SystemVerilog, intended for the
Xilinx Kintex-7 -3 speed FPGA. This folder should be opened as a Vivado project. Before running, be sure to generate the SystemRDL Verilog.

The `generated` directory is full of content generated by [PeakRDL](https://peakrdl.readthedocs.io/en/latest/).
Sources can be found in `rdl`, and outputs can be generated with:

```bash
peakrdl regblock rdl/keyboard_mmio.rdl -o generated --cpuif apb3-flat --top keyboard_mmio
peakrdl markdown rdl/keyboard_mmio.rdl -o docs/keyboard_mmio.md --top top
peakrdl html rdl/keyboard_mmio.rdl -o ../zenith-web/public/rdl/keyboard/
```
